Install Aplikasi Beragenda

Aplikasi ini mendukung PWA (Progressive Web App) dan dapat diinstall di layar utama Android dan iOS tanpa unduhan dari App Store/Play Store.

🍏 Untuk Pengguna iPhone / iPad (iOS):

  1. Buka di browser Safari.
  2. Ketuk tombol Share (ikon kotak dengan panah ke atas) di menu bawah.
  3. Pilih Tambah ke Layar Utama (Add to Home Screen).

🤖 Untuk Pengguna Android / Chrome:

Ketuk tombol "Install Sekarang" di bawah atau pilih menu browser ⋮ > Install App / Tambahkan ke Layar Utama.
